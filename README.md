## 一、仓库说明

本仓库用于存放《嵌入式系统》课程各次实验的**工程源码、实验文档和现象截图**。

按照课程要求，所有实验统一放在这一个公开仓库内，每个实验一个 `labXX_名称` 子文件夹，
不新建多个仓库，也不删除旧实验文件夹。

## 四、单个实验文件夹的内容约定

每个 `labXX_名称` 文件夹是一个**完整的 STM32CubeIDE 工程**（含 `.ioc`、`.cproject`），
可直接导入 CubeIDE 编译下载；除此之外固定包含：

| 路径 | 存放内容 |
| --- | --- |
| `README.md` | 实验目的、原理、关键代码、实验结果与总结 |
| `Core/`、`Drivers/`、`Startup/` | 工程源码与 HAL 驱动库 |
| `screenshots/` | 开发板运行现象截图 |
| `docs/` | 时序图、辅助脚本等补充材料 |

## 五、提交规范

- 每完成**一个完整实验**，执行一次 `push` 推送到本公开仓库；
- 实验调试过程中允许在本地多次 `commit` 存档，但不必每次修改都立即推送；
- `commit` 摘要采用 `labXX：做了什么` 的格式，例如：

  ```text
  lab01：完成 GPIO 初始化
  lab01：实现 500ms 间隔 LED 闪烁
  lab01：LED 点灯实验完整完成
  ```

- 编译产物（`*.axf`、`*.hex`、`build/`、`Debug/` 等）由 `.gitignore` 过滤，不提交到仓库。
