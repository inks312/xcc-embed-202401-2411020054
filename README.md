## 四、单个实验文件夹的内容约定

每个 `labXX_名称` 文件夹内固定包含三部分：

| 目录 | 存放内容 |
| --- | --- |
| `src/` | 工程源码（Keil / STM32CubeIDE 工程，或核心源文件） |
| `doc/` | 实验报告（`.docx` / `.pdf` / `.md`） |
| `screenshots/` | 开发板运行现象、串口输出、示波器波形等截图 |

## 五、提交规范

- 每完成**一个完整实验**，执行一次 `push` 推送到本公开仓库；
- 实验调试过程中允许在本地多次 `commit` 存档，但不必每次修改都立即推送；
- `commit` 摘要采用 `labXX：做了什么` 的格式，例如：

  ```text
  lab01：完成 GPIO 初始化
  lab01：实现 500ms 间隔 LED 闪烁
  lab01：LED 点灯实验完整完成
  ```

- 编译产物（`*.axf`、`*.hex`、`build/`、`Debug/` 等）由 `.gitignore` 过滤，不提交到仓库。
